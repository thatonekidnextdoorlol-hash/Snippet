# Snippet
A Discord bot designed to close threads to avoid Discord's 1000 thread limit.

## What Exactly Does Snippet Do?
Quite simple actually! Snippet provides server administrators with a dashboard showcasing active threads/forum posts and closes any in-active threads when needed!
